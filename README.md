# Auto Image Capture

**Free Windows Screenshot Automation Tool**

Developed by **B.A.S.E.**

Auto Image Captureは、指定したウィンドウや画面範囲を自動で連続撮影し、画像をPNG・PDF・ZIP形式で保存できるWindows向け無料アプリケーションです。

画像ビューアやページ送りに対応したアプリで、複数ページの画像を効率よく記録・整理できます。

## 主な機能

- **ウィンドウ指定撮影** — 指定したアプリのウィンドウを撮影
- **Drag Select** — マウス操作で撮影範囲を自由に指定
- **連続自動撮影** — 指定した枚数を順番に撮影
- **自動ページ送り** — 対応アプリへキー操作を送信
- **ページ変更検出** — 画像の変化を確認し、異常時には確認待ち・安全停止
- **出力形式** — PNG画像、複数ページPDF、ZIPアーカイブ
- **撮影の中断・復旧** — 保存済みセッションの確認と再出力
- **撮影設定** — 待機時間、保存先、画像保持などを調整

## インストール方法

1. ReleasesからZIPファイルをダウンロードします。
2. ZIPを右クリックして「すべて展開」を選択します。
3. 展開したフォルダーを任意の場所に保存します。
4. フォルダー内の `AutoImageCapture.exe` をダブルクリックして起動します。

**注意：** EXEだけを取り出さず、同梱ファイルをまとめて保持してください。

.NET Desktop Runtimeを別途インストールする必要はありません。

### Windowsのセキュリティ警告について

本アプリは現在、デジタル署名されていません。そのため、Windows SmartScreenなどによる警告や実行ブロックが発生する場合があります。

ダウンロード元とSHA-256を確認してください。Windowsのセキュリティ保護機能を無効化することは推奨しません。

## 基本的な使い方

1. 撮影したい画像やページを、対象のアプリで表示します。
2. Auto Image Captureを起動します。
3. 撮影対象のウィンドウを選択します。
4. Window Client AreaまたはDrag Selectで撮影範囲を指定します。
5. 撮影枚数、ページ送り、待機時間、保存先を設定します。
6. Test Shotで撮影範囲を確認します。
7. 必要に応じてTest Page Turnでページ送りを確認します。
8. Startを押して連続撮影を開始します。
9. 完了後、保存された画像・PDF・ZIPを確認します。

ページ送りの動作は、対象アプリのキー操作への対応状況によって異なります。

## 既知の制約と注意事項

- 撮影中は対象ウィンドウを遮ったり、他のウィンドウへ切り替えたりしないでください。
- 対象ウィンドウの前面状態やOS側のフォーカス制御によって、撮影・ページ送りが停止する場合があります。
- 過去のForeground関連の失敗について、一部の根本原因は未確定です。対象確認の安全機構を備えていますが、あらゆる状況で誤操作を防止できる保証はありません。
- 撮影完了後は、画像の欠落・重複・順序を確認してください。
- 重要な画像やセッションデータはバックアップを推奨します。
- DRMや著作権、プライバシーその他の権利・法令を遵守して使用してください。

詳細はZIP内の `KNOWN_ISSUES.md`、`TERMS.md`、`LICENSE.txt` を確認してください。

## プライバシー

Auto Image Captureはローカルで画像を処理するWindowsアプリです。

アプリ自身に、撮影画像の自動アップロード、アクセス解析、広告配信、診断ログの自動送信機能はありません。

撮影画像、セッション、設定、ログはPC内に保存されます。ウィンドウタイトル、ファイルパス、端末情報などがローカルの設定やログに含まれる場合があります。

詳しくは同梱の `PRIVACY.md` を確認してください。
